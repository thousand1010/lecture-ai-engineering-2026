## 宿題

- 取り組んだレベル：基礎
- やったこと：
  - `app/agent.py` の `INSTRUCTIONS` のうち、回答の末尾についての指示を1行だけ変更した。
    - 変更前：`回答の最後に、関係する回（第N回）を示す。`
    - 変更後：`回答の最後に、理解を確かめる確認問題を1問出す。確認問題の答えは書かない。`
  - 用語集を必ず検索する指示、ツールの docstring、検索処理は変更していない。
  - モデルを `gemini-3.5-flash-lite` にそろえ、変更前後に同じコマンドを各1回実行した。

    ```bash
    uv run python -m app.agent --trace 'LoRAとQLoRAの違いは？'
    ```

  | 比較項目 | 変更前 | 変更後 |
  |---|---|---|

- 気づき・疑問：
